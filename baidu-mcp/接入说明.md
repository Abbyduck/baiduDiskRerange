# 百度网盘 MCP 接入

本项目用本地 `bridge.mjs` 将百度 MCP SSE 服务转换为 stdio。依赖版本由 `package-lock.json` 固定。

```powershell
npm --prefix baidu-mcp ci
```

## 本地凭据

授权方式请核对[百度网盘 MCP 项目说明](https://github.com/baidu-netdisk/mcp)。拿到 Access Token 后，在 Windows 的项目根目录运行：

```powershell
.\baidu-mcp\Save-Token.ps1
```

在隐藏输入处粘贴 Token 或授权成功后的完整结果链接。脚本会将凭据用当前 Windows 用户的 DPAPI 加密，写入本机 `token.dpapi`，然后检查连接。不要把包含 Token 的链接提交到代码、聊天或日志。

如果授权后的结果页是空白，不能仅凭页面外观判断授权失败；结果链接的片段中可能包含凭据。不要把这个完整链接公开。

桥接也支持 `BAIDU_NETDISK_ACCESS_TOKEN` 环境变量；Python 盘点工具使用本机 DPAPI 文件。凭据和环境变量值不属于仓库内容。

## MCP 客户端配置

参考 `codex-config.example.toml`，将模板里的项目路径替换为本机绝对路径，再放入客户端使用的 MCP 配置。模板只开放文件列表与元信息工具。实际账号的 OAuth 授权范围由授权页决定，不会因为本地工具白名单而缩小。

```powershell
.\baidu-mcp\Start-BaiduMcp.ps1 -Probe
```

这个检查只报告服务器版本、是否提供凭据和工具名称，不打印 Token。凭据过期或环境变化后，需要重新授权或检查连接。

源码中的服务地址为 `https://mcp-pan.baidu.com/sse`。访问是否可用应以当前连接检查为准，本仓库不保存其他用户的授权结果。
